## 首项交付

形成正常图分组清单与 61/32 互补划分可行性记录。分组阶段只读取图像身份和图像内容，不以已有模型分数、FP 或 TP 选择分组阈值。

1. 查找真实采集批次、序列或工件标识，并记录来源。当前 pilot-manifest.csv 没有这些字段。编号接近与 dHash 接近可作代理，仍需标注其依据和局限。
2. 有可靠标识时按标识形成组。若只能使用代理，先写明有限个候选定义及图像侧选择理由，再登记具体边规则、连通分量定义和所有键。图像相似连通分量仅用于隔离该定义下的相似图，不能认证物理独立。
3. 对每个分组方案先计算组大小、最大组和“整组分入评价侧且图像数恰为 32”的分配数。若不能同时保留校准 61、评价 32，记录不可行，重新审定样本规模与预算后再继续。

该交付会决定能否延续原比较尺度，避免先计算结果再改变分组或样本数。

## 后续评测契约

固定 background 参考库、93 张正常分数和 212 张缺陷分数，固定 MAX、MID12、Q95、Q90，Q99 继续作为 MAX 恒等核查。把逐图均匀互补划分与整组互补划分并列分析。若有多个图像侧分组定义，全部记录，事前指定主要方案。

按既定规则枚举可行分配或固定抽样机制，报告四态比例、FP/TP 分布、预算触及程度和校准上尾的组成。所有阈值仍由每次划分的校准侧生成。比较结果条件于同一批已知分数和分组定义，属于事后敏感性分析。共同使用的缺陷集合只提供条件于该池的 TP 对照。

本任务回答原分组选择对结果有多大影响。新的规则或表示方法，另用分数未见的数据验证。后续可选的工作包括规则族改进或同条件参考库改进；先完成这项分组可行性检查，有助于为这些比较确定评价边界。
