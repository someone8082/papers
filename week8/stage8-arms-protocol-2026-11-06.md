# 第八阶段四臂驱动协议 v1

2026-11-06。状态 ARMS_PROTOCOL_FROZEN。本协议在生成任何抽样清单之前写定，第四节之后的全部口径不得按结果调整。主臂为 G1。

## 0 目的与解释边界

本协议只回答一个问题：在固定的 93 张 `test/good/background` 分数、8 张参考图、212 张缺陷与四条已定规则下，把逐图互补划分改为整组互补划分，并把与参考图近邻的 18 张组固定在校准侧之后，四态比例、FP/TP 与预算触及如何变化。

四条边界必须先声明：

1. 这是已见有限池上的事后敏感性分析。全部 93 张正常图与 212 张缺陷图都已在前六个阶段被打分，本文不产生新分数、不重新训练、不改参考库。
2. dHash≤4 的连通分量只是代理相似关系，不认证拍摄会话、物理独立或真实工件同一性；"整组"只表示在该代理定义下同属一个连通分量。
3. 缺陷集合固定不变，四臂共用，因此 TP 只提供条件于该池的对照，不构成跨条件的效应估计。
4. 每臂 10000 次的蒙特卡洛误差只描述本协议条件下的抽样分布，不是数据总体的抽样不确定性，也不能用于判断两臂差异的显著性。

记 93 张 test 正常图为 `U`，18 张参考近邻组为 `A`（`groups-dh4.csv` 中 `eval_eligible=0` 的唯一组，group_id 4），其余 75 张为 `E = U \ A`。66 个组中除 `A` 外的 65 组为 `G'`。

| 臂 | 单元 | 单元大小 | 目标 | 排除 | 分配数 |
|---|---|---|---:|---|---:|
| **I0** | 93 张单图 | 全 1 | 32 | 无 | C(93,32) = 8661069563374624785150762 |
| **G0** | 66 组 | 组内张数 | 32 | 无 | 1672489259948266974 |
| **I1** | 75 张单图（`E`） | 全 1 | 32 | `A` 固定校准 | C(75,32) |

- 每行的校准侧为 `U` 中未被选入评价的 61 张；`I1`/`G1` 下它恒含 `A` 的 18 张。

## 3 种子与抽样机制

```
seed(arm) = int.from_bytes(SHA256(UTF8("stage8-grouped-v1|20261106|" + arm)), "big")
```

`arm` 精确取 `I0`、`I1`、`G0`、`G1` 四个字符串。每臂建立**恰一个** `random.Random(seed)` 实例，连续抽 10000 次（有放回），`repeat_id` 从 0 起。

每次抽样：

1. `total = count(sizes, 32, excluded)`，用任意精度整数；
2. `rank = rng.randrange(total)`，只此一次，不转浮点；
3. `subset = decode(sizes, 32, rank, excluded)`，按 `SAMPLER-CONTRACT.md` 的字典序秩（指示向量 `(b_0,…,b_{n-1})`，`0<1`，`b_0` 最高位，逐组先列不选分支）。

禁止逐组抛硬币、固定选中组数、贪心取前若干组、把总计数转浮点、事后去重、按结果换种子。重复划分原样保留并统计重复数。

## 4 清单格式与键编码

每臂一个 CSV：`week8/outputs/arms-v1/manifest-<arm>.csv`，列固定为

```
arm,repeat_id,rank,eval_idx,eval_n,eval_sha256,cal_n
```

- `eval_idx`：该行评价图在**臂内键表**中的位置，升序，空格分隔。臂内键表 `image_keys` 在 `arms-plan.json` 中逐臂全列（`I0`/`G0` 为 93 张升序，`I1`/`G1` 为 75 张升序）。
- `eval_sha256`：把该行评价键按升序以 `"\n"` 连接后的 SHA-256。逐行可复原、可校验，同时把四个清单文件控制在可复核规模（合计约 7 MB），避免为每行重复存 93 个键。
- `cal_n` 恒 61，`eval_n` 恒 32；校准键由 `U \ eval` 唯一确定，不另存。

`arms-plan.json` 另含：每臂 `sizes`、`count`、`seed_hex`、`draws`、`image_keys`、`count_anchor`；分组臂的逐组 `{group_id, size, members, inclusion_probability}`；以及 `inclusion` 汇总。

## 6 评价口径

**阈值**（每次只用该行 61 张校准分数，升序 `s[0..60]`）：

| 规则 | 定义 | 说明 |
|---|---|---|
| MAX | `s[60]` | 最高校准分 |
| Q99 | 升序秩 `ceil(99·61/100)=61` | 与 MAX 逐位相同的恒等核查 |
| Q95 | 升序秩 `ceil(95·61/100)=58` | 描述性对照 |
| Q90 | 升序秩 `ceil(90·61/100)=55` | 描述性对照 |
| MID12 | `(s[59] + s[60]) / 2.0` | 最高两分中点，另有 `x60+(x61−x60)/2` 的 1 ulp 反例，故钉死此写法 |

判定一律 `score > threshold`（严格大于，等号不报警）。阈值以 hex 与十进制双写，读回时校验位型往返。Q99 与 MAX 位型不等即中止。

**四态**（顺序固定）：

1. `FP(MAX) ≥ 2` → `both_over_budget`
2. 否则 `FP(MID12) ≥ 2` → `mid_over_budget`
3. 否则 `ΔTP > 0` → `budget_gain`
4. 否则 `budget_no_gain`

`ΔTP = TP(MID12) − TP(MAX)`，`ΔFP = FP(MID12) − FP(MAX)`；实现须断言 MID12 的正常与缺陷报警集合分别包含 MAX 的对应集合。

**预算触及**：`min_threshold = min(MAX, Q95, Q90, MID12)`；`max_normal` = 该行 32 张评价正常的最高分；`slack = min_threshold − max_normal`。`slack > 0` 表示该行五条规则全部未消耗 FP 预算，即预算约束在该行不活跃。另报每规则 `FP=0` 的行比例。

**事后上界**（逐行记录，聚合报均值与 p05/p50/p95）：

- `c_star_tp`：61 个候选阈值中满足 `FP ≤ 1` 的最大 TP（TP 随阈值单调不增，等价于最低可行候选）。
- `u_tp`：高于第二高评价正常分的缺陷数，该点 `FP ≤ 1` 恒成立（严格大于）。
- `gap = u_tp − c_star_tp`。

**聚合**：四态计数与比例（附 `±1.96√(p(1−p)/n)` 的区间，仅描述本条件抽样）；每规则 FP/TP 的均值、中位、p05/p95、最大值、`FP ≤ 1` 比例；`ΔFP`/`ΔTP` 的均值与 `ΔTP>0` 比例；`slack` 的分位与 `slack>0` 比例；`FP=0` 全规则行比例；G0 中含 `A` 的图像进入评价侧的行数（期望约 0.15 行）。

## 7 自检与外部一致性

1. 四个 `count` 与外部锚逐位相等；`G0 − G1` 等于 `A` 被选中的分配数。
2. 每臂恰 10000 行；每行 32/61、互斥、并集为 `U` 或 `E∪A`；`rank < count`；行摘要可复原。
3. 包含概率：逐臂 `Σ s_i · p_i = 32`（精确 `Fraction`，不是浮点）；I0 每张 `32/93`、I1 每张 `32/75`；G0 中 `A` 的入选概率单独报告，并换算为"18 张组随机入选"的期望行数。
4. **I0 外部一致性**：I0 与第七阶段精确枚举覆盖同一 `C(93,32)` 空间，其四态比例应在 `3σ`、`σ=√(p(1−p)/10000)` 内与 `split-exact-enumeration.json` 的精确值一致（24.5357% / 63.0008% / 0.8693% / 11.5942%）。这是管线一致性检查，不是新结论。
5. `selftest` 覆盖：秩边界、单次 `randrange` 约定、行摘要复算、锚组排除、计数与包含概率恒等式。

四臂定义与单元划分、四个种子与抽样次数、秩枚举顺序、四条规则与分位秩、四态判定顺序、严格大于约定、固定缺陷集合、校准 61 / 评价 32 的规模、主臂为 G1。任何一项变更须出新协议版本并整轮重跑；不得按结果更换主臂或调换分组定义。
