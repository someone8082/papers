# 抽样器固定验收契约（第八阶段第二轮）

## 目标与范围

目标为实现可复核的“整组分配均匀抽样器”：给定组大小与评价目标，精确计数合法整组划分，把整数秩双射到合法子集，并据此均匀抽样。设计来源为 `../stage8-grouped-design-decision-2026-11-06.md` 第 4 节。

实验允许改动的唯一前缀为 `src/sampler.py`。验收器、夹具、守卫、本契约、第一轮全部产物均在范围外。新运行只衡量工程正确性，不以任何真实 TP/FP 优化实现或定义。

## 接口契约

四个函数，全部只接受整数与整数序列，不接触图像键、文件与分数。

`sizes` 是正整数序列，每个位置代表一个身份不同的组，同大小组分别计数。`target` 是整数且 `0 <= target <= sum(sizes)`。`excluded` 是组下标（0 起）的可迭代对象，表示永远不进入评价侧的组，默认空；其元素须为互异整数且落在 `[0, len(sizes))`。

`count(sizes, target, excluded=())` 返回满足 `sum(sizes[i] for i in S) == target` 且 `S ∩ excluded == ∅` 的下标集合个数，任意精度非负整数。合法输入无解返回 0；非法输入显式拒绝。

`decode(sizes, target, rank, excluded=())` 接受 `0 <= rank < count(...)`，返回升序整数元组，为被选组下标。

`sample(sizes, target, rng, excluded=())` 只调用一次 `rng.randrange(count(...))`，把结果交给 `decode` 并返回；`rng` 是任何提供 `randrange(n)` 的对象，`random.Random` 即满足。禁止逐组抛硬币、固定组数、贪心取前若干组、或把大计数转浮点。

`inclusion_probabilities(sizes, target, excluded=())` 返回长度 `len(sizes)` 的 `fractions.Fraction` 元组；`p_i` 是均匀合法分配中第 i 组被选中的概率，`excluded` 中的组为 0。若 `count(...)` 为 0（无合法分配），返回全 0 元组，不抛错。

### 秩的枚举顺序

`decode` 的秩升序与指示向量 `(b_0, …, b_{n-1})` 的字典序一致，其中 `b_i = 1` 表示选择第 i 组，`0 < 1`，`b_0` 为最高位。等价说法：秩等于把 `b_0` 当最高位的二进制整数。这正是“先列不选分支、其容量 `D(i+1, t)`，`rank < z` 则不选，否则选并令 `rank ← rank − z`”的顺序。该顺序必须固定，否则冻结的抽样不可跨实现复现。

### 拒绝条件

组大小非正、非整数或布尔；`target` 为负、非整数或布尔、或大于总和；`excluded` 元素越界、为负、重复、非整数或布尔；`rank` 为负、不小于 `count`、非整数或布尔。以上均须抛 `ValueError` 的子类（建议 `src.errors.InputError`），不得静默返回。

### 非目标

不读图像、不读分数、不写文件、不决定评价图与校准图之外的任何角色；不做逐图抽样。图像侧如何把 66 个组凑成 32 张评价图属于驱动脚本，不在本契约内。

## 固定种子与夹具

四臂种子由 `int.from_bytes(SHA256(UTF8("stage8-grouped-v1|20261106|" + arm)), "big")` 得出，`arm` 精确取 `I0`/`I1`/`G0`/`G1`，四个十进制值写入夹具，供实现与驱动脚本共用。每臂 10,000 次、有放回、独立 `random.Random` 实例，由驱动脚本执行；本契约只固定种子推导与抽样机制。

夹具 `sampler_fixtures/sampler-cases.json` 由 `sampler_tools/gen_sampler_fixtures.py` 以种子 20261106 生成 40 个小实例（组数 1–12、每组 1–6、target 在 `[0, 总和]` 均匀抽取、`excluded` 大小 0–2 均匀抽取），另存真实 66 组大小、强制校准组下标、三个锚定值、四臂种子与秩顺序声明。夹具只存输入与外部锚，不存可现场重算的期望值。
